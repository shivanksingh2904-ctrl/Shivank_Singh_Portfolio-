## ⚡ Getting Started

Follow these steps to run the portfolio locally.

### 1. Clone the repository

Replace the placeholder URL with your actual repository URL.

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
```

### 2. Open the project folder

```bash
cd YOUR_REPOSITORY
```

### 3. Add your profile picture

Place your portrait at:

```text
assets/profile.png
```

If your image has a different filename, update its path in `index.html`.

### 4. Configure your contact details

Open `data/site-config.json` and update the settings:

```json
{
  "email": "your-email@example.com",
  "linkedin": "https://www.linkedin.com/in/your-profile/"
}
```

Keep the JSON syntax valid, including quotation marks and commas.

### 5. Start a local server

If Python is installed, run:

```bash
python -m http.server 8000
```

Open the following address in your browser:

```text
http://localhost:8000
```

**Important:** Run the project through a local server instead of opening `index.html` directly with `file://`, because fetching the JSON configuration may not work when opening the file directly.

## 🌐 Deploy with GitHub Pages

1. Push the portfolio files to your GitHub repository.
2. Open the repository on GitHub.
3. Navigate to **Settings → Pages**.
4. Select the deployment source and branch, commonly `main`.
5. Select the repository root folder if your `index.html` is located there.
6. Save the configuration and wait for deployment.
7. Open the published URL and test the website.

If your portfolio is deployed under a repository path, verify that all asset paths and links work correctly.

## ♿ Performance & Accessibility

The portfolio includes several usability considerations:

- Responsive styling for different screen sizes.
- Support for `prefers-reduced-motion`.
- Reduced particle activity on smaller screens.
- Lightweight static architecture without a required build pipeline.
- A placeholder portrait for use before adding a personal image.

For production, also verify keyboard navigation, color contrast, focus indicators, image alternative text, and performance on slower devices.
